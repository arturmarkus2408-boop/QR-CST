# Cotton Stalk Technology — сайт-визитка

Одностраничный сайт-визитка ООО «COTTON STALK TECHNOLODGY» (ИНН 313 442 297) с QR-кодом.

**Адрес сайта:** https://arturmarkus2408-boop.github.io/QR-CST/

## Что на сайте

- Три языка: русский, узбекский, английский (переключатель вверху; язык запоминается, можно открыть сразу нужный: `?lang=uz`, `?lang=en`).
- Кнопки «Позвонить», «Написать», «В контакты» (скачивается визитка `contact.vcf`).
- Деятельность по ОКЭД 16.21.0, сведения о компании.
- Банковские реквизиты с копированием каждой строки и кнопкой «Скопировать всё».
- Свидетельства о госрегистрации (RU / UZ / EN, PDF).
- Карточка с QR-кодом и ссылки на Яндекс Карты и Google Maps.

## QR-код

Все QR-коды ведут на https://arturmarkus2408-boop.github.io/QR-CST/

| Файл | Для чего |
|---|---|
| `qr/qr-cst.svg` | Векторный QR — для типографии, визиток, баннеров любого размера |
| `qr/qr-cst.png` | QR с логотипом CST в центре, 2352×2352 px |
| `qr/qr-card.png` | Готовая карточка для печати (логотип + QR + подпись), 300 dpi |

## Структура

```
index.html          — страница
assets/styles.css   — стили
assets/app.js       — переводы (RU/UZ/EN), копирование, анимации
assets/             — логотип, иконки, изображения, превью для мессенджеров (og.jpg)
docs/               — свидетельства о госрегистрации (PDF)
qr/                 — QR-коды
contact.vcf         — контакт для сохранения в телефон
```

Тексты всех трёх языков лежат в `assets/app.js` (объект `I18N`). Изображения сгенерированы GPT-image.

## Публикация

Сайт публикуется через GitHub Pages: **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`**.
