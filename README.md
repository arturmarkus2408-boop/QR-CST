# Cotton Stalk Technology — сайт-визитка

Одностраничный сайт-визитка ООО «COTTON STALK TECHNOLODGY» (ИНН 313 442 297) с QR-кодом.

**Адрес сайта:** https://arturmarkus2408-boop.github.io/QR-CST/

## Что на сайте

Компактная визитка в одну колонку:

- переключатель языков RU / UZ / EN (язык запоминается; можно открыть сразу нужный: `?lang=uz`, `?lang=en`);
- кнопки «Позвонить», «Написать», «В контакты» (скачивается `contact.vcf`);
- контакты и адрес со ссылками на Яндекс Карты и Google Maps;
- реквизиты с копированием по строке и кнопкой «Скопировать все»;
- свидетельства о госрегистрации (RU / UZ / EN, PDF).

## QR-код

Все QR-коды ведут на https://arturmarkus2408-boop.github.io/QR-CST/

| Файл | Для чего |
|---|---|
| `qr/qr-cst.svg` | Векторный QR — для типографии, визиток, баннеров любого размера |
| `qr/qr-cst.png` | QR с логотипом CST в центре, 2352×2352 px |
| `qr/qr-card.png` | Готовая карточка для печати (логотип + QR + подпись), 300 dpi |

## Структура

```
index.html          — страница
assets/styles.css   — стили
assets/app.js       — переводы (RU/UZ/EN) и копирование
assets/             — логотип, иконки, изображения, превью для мессенджеров (og.jpg)
docs/               — свидетельства о госрегистрации (PDF)
qr/                 — QR-коды
contact.vcf         — контакт для сохранения в телефон
```

Тексты всех трёх языков лежат в `assets/app.js` (объект `I18N`). Фото в шапке сгенерировано GPT-image.

## Публикация
